# Incident_Response_Playbook
A cybersecurity project documenting incident response procedures and a practical investigation of Windows Security event logs.
Incident Response Playbook

Project Overview

This project documents a basic cybersecurity incident response playbook and demonstrates how Windows Security Event Logs can be used to investigate authentication events.

Objectives

- Understand the incident response lifecycle.
- Identify and review failed and successful Windows logon events.
- Document investigation findings and recommended response actions.
- Practice evidence-based incident reporting.

Incident Response Lifecycle

1. Preparation
2. Detection and Analysis
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

Practical Investigation

The project includes a review of Windows Security Event Logs, focusing on:

- Event ID 4625: Failed logon attempts.
- Event ID 4624: Successful logon events.

The observed events are documented as investigation evidence. Failed logons alone do not establish that an account was compromised.

Evidence

Screenshots of the Windows Security log investigation are included with the project report.

Disclaimer

This is an educational project using Windows event logs for learning and documentation. Findings should not be interpreted as proof of a security breach without further evidence.
